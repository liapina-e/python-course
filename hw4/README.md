# Домашняя работа 4

Проект Flask-приложения для выполнения ДЗ4.

## Описание
Приложение с API эндпоинтами:
- Информация о сервере
- Информация об авторе
- Сложение чисел через GET-параметры

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите сервер: `python server.py`
